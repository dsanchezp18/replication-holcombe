# data/final

## Purpose
Analysis-ready outputs of the cleaning step: the derived dataset and saved model objects, so every downstream script (R, Stata, Python) builds derived variables exactly once.

## Contents
- `corruption_final.rds` / `corruption_final.csv` — `data/raw/cor1.csv` plus derived variables (`col_uk`, `lgdp_pc`, `lpop`, `lfor`, `hinc`, `america`).
- `main_regression_models.rds` — fitted model objects from `code/analysis/01_main_regressions.R`, reused by `code/analysis/04_summary_tables_export.R`.

## Naming Convention
`snake_case`, suffixed `_final` for analysis-ready data, `_models` for saved fits.

## Dependencies
Generated by `code/cleaning/01_clean_corruption_data.R` and `code/analysis/01_main_regressions.R`. Do not edit these files by hand — regenerate them instead.
